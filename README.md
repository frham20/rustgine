# AI generated Rust based DX12 engine

- PBR Rendering
- HDR Rendering
- Deferred Rendering
- GPU terrain
- GPU grass
- Shadow Map
- Rayleigh scattering
- Raymarched clouds
- ImGUI integration for debug operations
